# Deadlock Cards

Cartas estilo FIFA para jogadores de Deadlock. Projeto 4fun gerenciado pelo Hagizao, sem afiliação com a Valve.

## Uso de IA

O código deste projeto foi desenvolvido com auxílio de IA. **A arte não**: ilustrações, logos e visuais das cartas são feitos por pessoas.

## Rodando local

```bash
npm install
cp .dev.vars.example .dev.vars
npm run db:migrate
npm run dev
```

Abre em `http://localhost:5173`. Para contribuir, veja o [CONTRIBUTING.md](CONTRIBUTING.md).
